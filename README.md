# Identity work

Brand identity for three concept brands, Fold Supply, Fine. and Notch, plus two smaller studies. Static site: plain HTML, CSS and a little JavaScript, no build step.

## Put it online with GitHub Pages

1. Create a new repository and upload everything in this folder (keep the folder structure).
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. After a minute the site is live at `https://<user>.github.io/<repo>/`.

To look at it before uploading, open `index.html` in a browser.

## What's where

```
index.html            three marks + smaller studies
fold-supply/          Fold Supply: mark, colour and type, icons, motion, in use, full brandbook
fine/                 Fine.: the F, carved bars, reveal, brand family, lit gold
notch/                Notch: logo, colour, measurement graphics, pattern bundle, catalogue, other routes
downloads/            Fold Supply brandbook as a PDF (18 pages)
assets/marks.js       the three logos as SVG, used for the hover moves and page openers
assets/site.css/.js   layout, the moves, the zoom-out openers, the image viewer
assets/img/           every board and page as WebP
```

Motion respects "reduce motion" settings: the marks stay still and the openers start fully zoomed out.
